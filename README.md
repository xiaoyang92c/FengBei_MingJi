# FengBei_MingJi · 丰碑与铭记

> 先有锤声，才有火车声。路修好了，别忘了修路的人。

围绕成渝铁路建设与筑路民工纪念碑展开的沉浸式网页叙事项目，也是“成渝铁路工业遗产数字记忆馆”的第二章。观众从老电视序幕出发，穿过三处记忆空间，收录五条线索，最终回到碑前。

项目以手机竖屏体验为主，同时适配电脑横屏，完整体验约需 **3—5 分钟**。

**[GitHub 仓库](https://github.com/xiaoyang92c/FengBei_MingJi)**

### 主要交互

- **老电视序幕与终章**：开屏亮线、扫描线、静电颗粒、文字故障及余辉效果；入口和重看选项均采用先选择、再确认的方式。
- **门窗与空间穿梭**：外墙连接三个窗口，进入、退出时连续推进或收回镜头，门洞与室内共享对应的场景取景。
- **五条线索阅读**：点击编号打开资料页，以“所见—史料—解读”组织内容，配合落锤、接轨、列车、碑名和碑体层级等循环动效。
- **现场手记与记忆册**：纸页展开与折叠、滚动逐字排印、照片和收录目录；首次进入场景即可探索，无需拾取记忆册。
- **自动循环年表**：1950、1952、1954 三个年份依次播放；上一段记事逐字消失后，下一段逐字出现。
- **分层声音**：背景音乐、场景环境声、穿梭风声、纸页声、铅笔声和电视声分别控制；支持静音。
- **移动端体感视差**：支持手机倾斜、自然握姿校准、缓动与限幅；电脑端使用鼠标视差。开启系统“减少动态效果”时停用体感并简化动效。
- **本地收录进度**：使用 `localStorage` 保存五条线索的收录状态，无需账号或后端数据库。

## 操作方式

1. 在电视序幕选择有声或静音体验，再次点击确认。
2. 在外墙窗口通过左右箭头、横向滑动或键盘方向键切换空间。
3. 点击窗口或“进入空间”，点击场景内的编号阅读并收录线索。
4. 通过顶部“现场手记”和“记忆册”查看资料与进度，通过“切换空间”返回窗口。
5. 收齐五条线索后，记忆册会定位到终章入口；点击“读终章”进入电视片尾。
6. “再看一次”保留进度，“重新开始”清空进度；两者均回到首页开屏。

电脑端可拖动场景轻微观察，`Esc` 可关闭线索页、手记或记忆册。手机端可通过左下角的体感开关启用或关闭倾斜视差。

## 本地运行

### 环境要求

- Node.js **20.19+** 或 **22.12+**。
- npm，以及支持现代 JavaScript、CSS 和 Web Audio 的浏览器。
- 运行网页不需要 Python；Python 仅用于可选的历史素材处理脚本。

### 安装与启动

```bash
git clone https://github.com/xiaoyang92c/FengBei_MingJi.git
cd FengBei_MingJi
npm ci
npm run dev
```

根据终端输出打开本地地址，默认是 `http://localhost:5173/`。

### 构建与预览

```bash
# TypeScript 类型检查，并生成 dist/ 静态文件
npm run build

# 预览构建后的版本，默认地址为 http://localhost:4173/
npm run preview
```

### 手机调试

```bash
npm run dev -- --host 0.0.0.0
```

手机与电脑连接同一网络后，可以通过电脑的局域网地址访问。**体感功能需要 HTTPS 安全上下文**，普通 HTTP 局域网地址只能调试页面与触摸操作；可使用已部署的 HTTPS 站点验证体感。需要请求动作与方向权限的浏览器，会显示“开启体感”按钮。

收录进度按浏览器与域名单独保存，不会跨设备同步。存储键为 `fengbei-memory-v2`；可通过终章“重新开始”清空。

## 技术实现

| 技术 | 用途 |
| --- | --- |
| TypeScript | 页面状态、Hash 路由、交互与音频调度 |
| Vite | 开发服务与静态构建 |
| GSAP、CustomEase、ScrollTrigger | 镜头穿梭、纸页、文字与滚动动画 |
| Three.js 数学工具 | 镜头参数及手机相对姿态计算 |
| Web Audio API | 环境音叠加、音量包络、循环与静音 |
| Device Orientation API | 移动端倾斜输入 |
| SVG、CSS、Canvas | 图记、控件、光学滤镜、颗粒与穿梭视觉 |

当前场景以 DOM、CSS 与图片构成，**不加载历史 GLB 碑体模型或方块占位**。宽屏使用横版场景图，手机及纵向窗口使用方形构图；线索点根据对应源图的位置投射至屏幕。

## 素材与史料说明

- 写实场景由 imagegen 生成，碑体形制参考项目中的实碑照片与地方资料；生成图不作为真实历史影像、实地测绘或原碑拓片。
- 手机场景使用原生 **1254×1254** 图片，桌面横版为 **1672×941**；网页资源以 WebP 保存。
- 照片上的日期表示叙事事件时间，不表示图片拍摄日期。
- 声音素材由用户提供。项目未附统一的素材再分发授权，复用前请结合资源清单确认相应使用范围。
- 历史模型、贴图及视频演示素材保留为设计过程资料，当前体验没有人物视频入口。
- 网页使用 Google Fonts 的 Noto Sans SC、Noto Serif SC，并提供本地字体回退。

## 部署与检查

项目可部署为纯静态站点，构建输出目录为 `dist/`。已移除 Sites 的本地发布配置，后续直接在此仓库修改、提交和推送。`node_modules/`、`dist/` 等依赖和构建产物不提交到 GitHub。

资源使用 `/assets/…` 根路径，部署在站点根目录即可；如果使用带仓库子路径的 GitHub Pages，需要同步调整构建和资源路径。

```bash
npm run build
node scripts/check-device-tilt.mjs
node scripts/check-mobile-runtime.mjs
```

上述命令分别进行类型检查与构建、模拟体感事件检查，以及移动端音频状态和加载数字居中的回归检查，均不请求真实设备权限。实际传感器手感与音频体验仍需在真实设备上确认。

“返回记忆馆”和“进入下一章”的外部地址尚未接入。

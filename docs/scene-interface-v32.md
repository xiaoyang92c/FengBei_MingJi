# 场景与记忆册 v31–v32

## 场景

- 两侧入口固定等高：桌面 64px，移动端 58px。左侧显示章节、收录数与进度刻线，点击进入本章手记；右侧显示记忆册总进度。
- 热点用测绘菱形、线索编号和短标签表达；完成图标为 SVG 路径，不使用字体对勾。
- 移除场景中独立的讲述按钮，工具与协作详情内保留人物讲述入口。视频仍是明确标注的演示影像。
- 修复 `.clue-tools`、`.clue-together` 的旧手机定位规则误作用于整个详情页的问题，规则仅匹配热点按钮。
- 详情沿用同一张完整场景和共同镜头，取消大幅局部平移放大；保留鼠标位移、780px 透视、鱼眼、暗角和颗粒。滚动阅读仅使用小幅画幅变化。

## 记忆册

- 以“成渝记忆”旧报纸呈现报头、图记、线索索引及 1950／1952／1954 时间线。已收录和待发现条目都可进入对应内容。
- 本章入口只显示对应章节的条目，并提供全部记忆入口。收录数、完成标记与终章状态使用现有浏览器进度。
- 打开时纸张轻微倾斜展开，内容依次显现；关闭时整张报纸向上收回。纸张持续响应鼠标，颗粒沿用全站画布，减少动态效果时关闭。

## 声音

此为 v32 历史记录；v33 已替换为用户提供的真实音频文件，见 `audio-mix-v33.md`。此前 `src/scene-audio.ts` 生成三组 24 秒立体声循环：锤凿、碎石与非语言人群底纹；列车轮节与蒸汽；山风。它们是设计音效，并非历史现场录音或真实口述。观众开启声音后播放，换场景交叉淡化，阅读时降低音量，隐藏页面或静音时淡出。

# 现场手记与折叠封面

## 折叠状态

- 记忆册和现场手记仍使用两半报纸折叠，照片展开后不再次入场。
- 折叠背面按刊头、居中题名和说明、底部收录信息组织。题名上下线同为 `--control-stroke`，不旋转标签、不使用厚线。
- 记忆册题名固定为“成渝记忆”；手记显示当前场景名，刊头显示场景序号，底部显示本章收录数。
- 狭窄屏幕和横屏分别收紧字号、间距，保留纸面留白。

## 现场手记

- 顶部固定显示“现场手记”、当前场景、收录进度及关闭按钮。删除下方“现场 / 观察点”固定栏目和阅读进度线。
- 正文直接滚动阅读；照片保持水平，边框不突出固定刊头的遮挡范围。删除纸面中央的额外竖向折痕。
- 标题改为居中的报纸章首：上方以两段短细线引出“现场手记 / 第 n 章”，中间加大章名并舒展字距，下方放当前场景的短句；取消“当前章节”和分散在右侧的计数。标题、照片、观察提示和本章线索按阅读顺序排列。删除斜置“勘察记录”、粗黑分隔线及重复的三场景标签。
- 观察点与记忆册条目共用序号、状态、标题和箭头的层次，悬停涂鸦覆盖整条观察点区域，左右端点向条目边缘展开，与记忆册一致。进入线索时保留选中反馈再折叠离场。
- 删除现场手记内跳转记忆册的按钮。页尾只保留文字信息。
- 保留点击条目的选中反馈；切页清理点击监听。减少动态效果设置仍由共享纸张动效处理。

按用户要求仅构建和检查源代码，视觉效果由用户在预览中查看。

各章标题下的场景短句和折叠封面的对应副文去掉末尾句号；其他正文保留正常标点。首次进入空间直接显示现场手记、记忆册与线索点，删除拾取记忆册流程。

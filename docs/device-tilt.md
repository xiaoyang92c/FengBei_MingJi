# 移动端倾斜视差

- 手机端以 `deviceorientation` 的相对姿态接入原有鼠标视差入口，门窗、场景、线索点与场景底部控件沿用现有相机关系。桌面继续使用鼠标，触摸拖动仍可平移场景、切换空间。
- 仅在主指针为触摸的设备上提供体感，所有浏览器默认关闭，包括不需要显式请求权限的浏览器。用户点击声音开关左侧的体感按钮后才开始授权和连接，在点击事件内调用 `DeviceOrientationEvent.requestPermission()`。拒绝后不自动重复弹出系统请求。
- 开关只显示“体感 关”和“体感 开”；授权中、连接中、被拒绝或没有有效数据时都显示“关”，首次收到有效数据才显示“开”。连接期间防止重复请求。手动关闭在本次页面会话内保持；重新开启沿用已授予的权限。
- 第一帧有效数据以自然握姿为基准，使用相对四元数处理竖直握持与角度跨界。按横竖屏角度转换两个视差轴，旋屏、从后台返回以及重新进入探索页面时重新取基准。
- 0.35 度小范围不产生偏移，约 14 度有效倾斜对应 0.6 的归一化偏移上限；100ms 低通缓动接相机缓动。小幅倾斜的响应约为上一版的两倍。相同姿态不重复发出相机更新，稳定后停止插值帧循环，画面偏移限制在素材覆盖范围内。
- 手机端以平移表达视差，避免动态 3D 旋转和转场裁切产生冲突。穿梭中冻结视角输入，到达新场景时重新校准自然握姿。触摸移出屏幕不会触发鼠标归中。
- 记忆册、手记、首页、终章、页面隐藏及系统减少动态效果状态下停止传感器监听。没有有效数据时在 3.5 秒后停止等待，允许点击重试。模块热更新时清理监听、计时器与帧回调。
- 真实手机访问需要 HTTPS 安全上下文。电脑上的 `localhost` 可作为开发例外，普通 HTTP 局域网地址不属于该例外；此时开关显示“关”并禁用，通过辅助标签说明需要 HTTPS。不支持传感器的设备隐藏开关。

## 检查

`node scripts/check-device-tilt.mjs` 使用真实模块与模拟传感器事件检查姿态基准、横屏轴向、竖直握持、角度跨界、限幅、静止去重、授权批准/拒绝、无数据重试、后台暂停、手动关闭、减少动态效果与清理。`npm run build` 检查类型并生成预览资源。按用户既有要求不做浏览器视觉检查；真实设备的传感器手感仍需手机体验确认。

参考：[Device Orientation and Motion](https://www.w3.org/TR/orientation-event/)、[MDN deviceorientation](https://developer.mozilla.org/en-US/docs/Web/API/Window/deviceorientation_event)。

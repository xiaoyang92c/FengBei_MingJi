# 电视片尾

终章改为与首页同一台 CRT 的片尾播出，进入时把当前整页收束为亮线并关闭，再亮屏显示片尾。

- 共用 crt-display.ts 的屏幕结构；终章取消屏幕外边距和圆角，开机、稳定画面均直角铺满视口。保留绿色荧光画面、扫描纹理、弧面位移和低分辨率静电颗粒；字号继承、亮度起伏与静态曲屏强度一致。
- 布局从上到下为频道信息、三个历史年份、结尾题名与短句、五条线索字幕、纪念碑名称、“本集终”、重看菜单及记忆册和声音工具。字幕内容严格居中，“五条线索”在左、“都记下了”在右；三者组成紧凑居中行，使用固定字幕窗和 9—12px 列间距，取消上下分隔线。重看菜单与工具区上移，屏幕上下采用同一留白变量；手机版保留同样顺序，小高度屏幕可在屏内滚动，不显示滚动条。
- 终章开机与首页使用同样的亮线、荧光扩散和逐字信号恢复；复用开机音轨，在电视开机段 0.08 秒发声、1.6 秒后启动电视低鸣；从报纸进入时开机段在整页关闭后延后 0.7 秒开始。开机音解码后同步启动，菜单在显字结束后开放。
- 五条线索以 28px 高字幕窗逐项上移，每项停留 2.6 秒、移动 0.7 秒；尾部复制首项，让循环复位发生在相同画面上。
- 从记忆册点击“读终章”不折叠报纸，而是把当前整页截图层垂直收成细线，0.4 秒时完全移除，亮线收去后短暂暗场，再开始电视开屏。纸面关闭后不透过电视显示；底层为实黑，纸面副本保留滚动位置但不挂载阅读脚本。
- “再看一次”和“重新开始”与首页使用同款外围选框和二次确认：第一次点击选定、框闪两次后固定，第二次点击同一项才执行。更换选项、上下键切换或 Escape 会重置确认；悬停只预览亮底，确认后留出 0.26 秒播放按键声。确认后暂停字幕轮播，全部文字（包含当前滚动字幕的序号与题名）一起失同步消散，约 0.97 秒直接衔接 #cover 的开屏和调谐。重看流程不压缩画面、不播放关机音，不追加关机序列。再看一次保留收集；重新开始清空收集。
- 电视片尾继承故事的声音开关；回到首页仍按原规则默认开启声音。片尾继续播放叙事 BGM（0.075），与电视低鸣叠加，进入终章时不暂停或重置音乐位置，工具按钮使用电视按键声，不使用铅笔声。
- 记忆册工具仍可返回档案册，该工具保留关机后回到报纸的过渡。片尾没有尚未接入的外链按钮。
- 减少动态效果时直接呈现静态片尾，显示五条字幕全文。页面隐藏会暂停时间轴与字幕，切页清理事件、时间线、噪点 ticker 和曲屏尺寸监听。

验证采用 TypeScript 检查、生产构建、两种 CRT 生成标记的嵌套和关键节点检查，以及在内存 DOM 适配器下运行实际重看菜单事件处理器，检查首次点击、更换选项、Escape、方向键和第二次执行。依照用户既有要求，不进行浏览器画面检查。

离场由共用 crt:leave 事件冻结当前字幕与开机时间轴。滚动字幕逐字构建后参加故障切片与残影；声音文字被更新后，也会在离场前重新拆字，避免文字遗漏。

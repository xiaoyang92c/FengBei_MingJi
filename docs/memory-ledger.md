# 成渝记忆：铁路档案册

记忆册采用折叠报纸的形式，保留纸张、朱红与固定题名“成渝记忆”，以及正文、目录和五条线索条目。

## 版式

- 题名恢复居中，以报头横线组织标题区域。删除标题下的五个圆点、侧面年代栏及布面装订边，左右留白对称；不恢复歪斜的“铁路手记”标签。
- 顶部目录分卷首、线索、年表和终章，滚动时保持可用，标明当前部分与整册阅读位置。合册按钮留在目录右端。
- 正文在桌面采用文字与照片并置，在窄屏依次排列。照片不旋转、不加投影，保留等宽纸边和右下角日期；没有单独入场动画。
- 线索部分的说明“五条线索 / 从工具到碑文”、题名和 01—05 计数统一右对齐。
- 五条线索改为报纸目录条目：去掉左侧贯穿线及序号方框，序号、章节和收录状态置于同一行，标题与统一的方框箭头同排，摘要紧随。桌面标题与摘要并列，窄屏上下排列；整条均可点击，待发现条目仍回到相应场景。
- 年表改为紧凑的横向三年份轮播区：1950 开工、1952 全线通车、1954 建碑奠基。三列年份保留字距，下方用细横线连接节点；年份自动按 1950→1952→1954→1950 循环，每篇停留约 4.4 秒。红线平滑推进或收回，当前节点半径 4，其余节点半径 2.5；随红线经过的节点保留红色，尚未经过的节点为灰色，回到首年时随线收回；记事按阅读顺序逐字收去，最后一字消失后稍作间隔，再按顺序逐字印出下一年份的日期、标题和正文；不做整段淡变或上下卷动。没有点击入口和操作提示。整段约 430—500px，不再使用长弯线和三段高列表；终章仍在实际进入阅读位置后激活。
- 手机版适配至 320px，边框使用统一的 `--control-stroke`。

## 动效与操作

- 合册时先复制当前纸面，再将原纸面的透明度与可见性同时归零，避免内部显字元素越过父级的隐藏状态残留在背景中；年表记事自身继承纸面可见性。
- 记忆册与现场手记共用原有的两半纸张折叠：折好的报纸滑入后展开，关闭时折回再退场。已移除书籍封皮动画，照片随报纸保持原样，不在展开后再次入场。
- 折叠背面的题名居中。记忆册为“成渝记忆”，现场手记按当前章节显示“开山筑路”“铁路贯通”或“回到碑前”，并使用对应章节说明。
- 折叠封面现在采用刊头、居中题名与副文、底部收录信息三段排版；题名上下细线等粗。现场手记的新固定栏目与版式见 field-notes.md。
- 目录条目进入视野后，标题从不可见开始逐字印出，随后摘要逐字接续，底部分隔线横向展开。每条在本次打开时播放一次，初始视野中的条目也会播放；照片仍不重新入场。
- 悬停、键盘聚焦时，铅笔涂鸦覆盖整条条目，包含序号、标题与摘要，箭头底色与题名联动；点击后保留该条反馈再折叠离场。涂鸦按整条条目的真实尺寸绘制，仍使用既有铅笔音效。没有整册随鼠标漂动。
- 目录采用局部平滑滚动，不修改路由；键盘聚焦可用，手动滚动可中断目录跳转。
- 点击“读终章”将整个当前页收束并关闭，再开屏显示电视片尾，不执行报纸折叠；背景音乐继续与电视低鸣叠加。片尾的两个重看选项在文字故障消散后直接接首页开机，不额外播放关机。电视片尾详见 tv-finale.md。
- 收齐第五条仍自动打开记忆册，报纸展开并等候字体、照片就绪后滚动至终章，定位会让开顶部目录。
- 年表在折页完成及尺寸、字体变化时重新测量。标题、年份与首篇记事各自滚入视野时逐字揭印；线路描出，三个节点沿线依次出现。首篇文字与线路出场结束后才开始自动循环。滚出视野或页面进入后台时暂停，回来后继续。减少动态效果时静态展示全部三篇记事。切页清理监听和时间轴。
- 减少动态效果时直接显示报纸，目录立即定位。切页移除折叠层、滚动监听、观察器和 GSAP 动画。

按用户要求仅做源代码检查和构建，不进行浏览器视觉检查。

## 文字的循环节奏

- 卷首题名去掉“锤声”后的逗号，保留“先有锤声 / 才有火车声”两行。锤声仅上下提起、敲下和轻微压缩回弹，左侧留出 .13em 安全间距，不旋转压到“有”字。随后火车声三个字轻微依次抬升、回落；删除声波装饰，两组依次循环，不新增音轨。
- 终章入口短句先让“路修好了”四字依次轻弹、微微摆动和压缩回弹后落定，再强调“修路的人”的墨色，细下划线缓慢写出、停留和收回。
- 动作作用于词组容器，逐字入场仍作用于内部字符，互不覆盖。两处循环仅在文字可见时播放，页面隐藏和滚出阅读区时暂停；关闭页面时清理。减少动态效果时显示静态文字。
- 首次进入场景直接展示手记、记忆册、线索点与切换空间控件，删除拾取记忆册的引导及其存储状态。
- 删除收录线索后的弹出提示与嘉奖纸笺，收录进度通过场景计数和记忆册呈现；收齐第五条仍自动打开记忆册终章。保留播放失败、未接入入口等必要的系统消息。

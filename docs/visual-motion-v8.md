# v8 选择空间首页与声音

- 选择空间仍使用同一张横向石墙和三扇透明门。`scripts/build_long_wall.py` 另外把原树影加工为 `tree-shadow-long-v8.webp`：三个影像片段在横向重叠处和外边缘渐隐，随整条墙移动，消除单张树影在墙面上结束时的直线边界。
- 增加墙面中心的宽范围暖光，树影浓淡和位移更明显。文字与选择页控件取消投影；选择页左上角不再显示记忆册，进入空间后仍可使用记忆册。
- 选择页相机以 `1.18` 倍留出画面边缘余量，鼠标跟随位移与倾斜增大。拖动墙面或门洞时，石墙与门一起跟手移动；达到阈值后落在相邻入口，距离不足则回弹。门洞拖动不会触发进入。
- 手机视口的门缩至 `62vw`（外层相机留边后，视觉宽度约 `73vw`）。
- 用户提供的 `sicuan.m4a` 原文件使用 Opus 编码，已转成浏览器兼容的 AAC M4A，位于 `public/assets/audio/sicuan-bgm.m4a`。仅在用户主动选择有声或点击声音开关后播放；静音、标签页不可见或打开人物视频时暂停，返回后续播。进门穿梭音效保留。

验证：在 1440×900 的左右鼠标极限位置检查墙面不露底；在 390×844 和 320×700 检查门尺寸与横向溢出；在 390×844 验证从门洞拖动切换且不误进入、进入按钮可用；验证背景音乐的播放、音量和暂停状态。关键画面在 `output/screenshots/v8-select-*.png`。

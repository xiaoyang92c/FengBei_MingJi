# 门洞、场景与房间控件（v15）

## 画面交接

选房页的门内预览与房间共用 `room.scene`。进入时读取当前门框和门洞的实际边界；转场层只渲染一张场景图，门洞裁切区域按门框的中心、位移和缩放同步扩大。图片从门内特写连续退至房间构图，门框超出视野后才移除转场层。退出沿同一轨迹反向播放。此方式避免了两张独立画面在缩放时出现矩形边角。

进、退场各约 1.08 秒。进入使用 `power2.out`，退出使用 `power2.inOut`。房间路由在门框仍遮住交接区域时切换；线索标记随后浮现。选房标题、进入按钮与声音控件在进入时上移淡出，返回时下移淡入。房间线索、讲述入口、切换按钮和声音控件同样有进出动效。

## 房间两侧信息板

左侧是深色线索记录板，列出当前空间的线索及收录状态；右侧是浅色记忆册签，显示总收录数和最近收录的线索，并可打开记忆册。进入时底色分别从左、右展开，再伸出板面与文字；退出时逆序收回。内容取自本地 `collected` 状态，收录后再次进入会更新。

## 验证

`npm run build` 通过。已在 1440×900 逐帧检查筑路现场的进入和退出，在 390×844 检查碑前进门，在 320×700 检查三处空间的双向进出、可见线索数（2、2、1）、转场层清理和页面错误；未出现转场矩形边角或运行时错误。关键截图见 `output/screenshots/v15-*.png`，窄屏线索状态见 `output/screenshots/v14-room-collected-monument-320.png`。

场景、门框及碑体仍为艺术化展陈素材，不是历史照片或原址复原。

# 满屏木门与电视序幕

- 两个全高门扇覆盖整个画布，使用同一张木门艺术化照片，按中缝分割，保留木纹和五金比例。门叶外侧为铰轴，用不同起步时间和同一条缓动曲线模拟重量。
- 封面、声音选择始终在同一棵 DOM 中。开门完成与关门完成都不重新 render。移除旧的等待开启版式，声音切换也不再重建封面，避免内容与门扇闪回。
- 电视内容固定为标题、有声进入、静音进入和合门按钮。开机先出现细亮线，再展开内容，元素分段点亮。信号亮度与每段文字持续轻微波动，并有缓慢扫描线；减少动态效果时全部关闭。
- 关门先压扁信号为亮线，亮线收为一点，再由左右门扇错时合拢；标题最后恢复。音效使用用户的开木门录音，关门音量为 0.45。
- 操作过程中按钮禁用，隐藏层设为 inert；结束后将焦点交给对应的下一步按钮。

# 加速模糊 v25

2026-10-15。

- 横向切窗根据逐帧位移速度计算高斯拖影，手机最高 9px、桌面最高 13px，主要沿横轴扩散。拖动、释放和箭头切换共用该逻辑；停止、调整尺寸和历史返回时清理滤镜。
- 进入窗口根据门框的缩放速度计算屏幕空间模糊，最高约 20px，再除以当前窗框倍率，避免放大后模糊失控。最后 22% 的推进逐渐清除模糊。
- 场景使用缓存的低分辨率径向透明度遮罩，只让边缘产生轻度速度模糊，中央主体保持清晰。滤镜内合成同一场景的清晰中心和模糊边缘，不新增场景背景层。
- 退出沿同一套速度模糊逻辑回收；完成时门框与边缘模糊均归零。减少动态效果时跳过穿梭与模糊。

验证：`npm run build`、`git diff --check`；浏览器连续取帧记录横向模糊 2.88 → 1.08 → 0.24，进入边缘模糊 0.56 → 0.89 → 1.27 → 0。完成后 flight 节点移除，门框模糊为 0 0。过程截图见 `output/switch-blur-v25-*.jpg` 与 `output/entry-blur-v25-*.jpg`。

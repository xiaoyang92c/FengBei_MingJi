# 三章铁轨叙事与门洞转场（v17）

## 叙事与画面

1. **开山筑路**：一段尚在铺设的钢轨通向山口。先看工具与共同作业的人。
2. **铁路贯通**：同一视觉母题变成可通行的双轨，列车驶入山间站台。时间线从开工走到全线通车。
3. **回到碑前**：一段旧钢轨被保存为纪念物。暂以简洁方体标示碑的位置，题名与建碑背景由文字和信息图说明；方体没有史实形制含义。

三幅 1672×941 场景图为内置 imagegen 生成的**艺术化场景**，不是历史照片，也不对应具体站点或纪念碑原址。提示词共同限定：真实摄影质感、克制的年代色彩、细颗粒、清晰的中心轨段、窄幅窗口可辨识、无可读文字或虚构铭牌。各章分别限定开凿山口与铺轨、山间通车列车、保存的旧轨段与空白纪念位置。第三章改用 v18 构图，让保存的轨段沿画面纵深进入手机窄窗中心。生成原图位于 Codex `generated_images`，站点使用压缩 WebP；资源路径和性质见 `public/assets/asset-manifest.json`。

## 窗内与室内的同一画面

`room.scene` 是每章唯一的场景图片。选房页的门洞、穿梭层与室内层都使用它。门洞的图片不是在窄矩形内单独执行 `cover`：脚本读取门洞屏幕位置和实际缩放，把一张相当于全屏场景的图片放到门洞后面，令屏幕上的构图坐标一致。

窗内图片相对室内为 `0.5` 倍，穿梭时随门框与门洞裁切同步连续变到 `1` 倍；退出则反向缩回。缩放原点固定在视口中心，门洞边界和门框从当前实测边界推导。窗内、穿梭层与室内场景采用同一张 1672×941 图片，三者的画幅均四周多留 8% 余量；预览不再对包含图片的整扇门施加滤镜，以免缩放时重采样变软。穿梭镜头、外墙与室内层使用同一鼠标偏移，转场中持续响应指针；路由交接后继续保持当时的镜头位置。门框超出画面后，房间两侧线索板与按钮再出现。

# 线索专页

- 五条线索专页统一从视口下方向上推出；场景小标题从视口上方向下滑入。关闭、收录和 Escape 离开前，正文向下拉出、场景小标题向上收回，结束后才更换路由。入场由 GSAP context 管理，离场纳入导航时间轴；减少动态效果时直接显示或切换。
- 删除固定的“看现场 / 读资料 / 再想一想”导航与角落阶段标签，保留正文中的三个阅读段落；顶部仅保留专页刊名和关闭按钮。阅读面板可滚动，但不显示滚动条。删除视频入口、视频占位层、路由和播放操作。
- 手记引语不再使用左侧竖线。现场手记标题采用居中章首，章序、章名与场景短句分别排印。

## 共用过渡

- 场景 UI 的进退场共用同一套时间轴：切换空间、声音按钮、线索序号及首次提示整体上移淡出；现场手记与记忆册入口依次收起文字、左右滑出纸签、收回底色。打开任一阅读页前先完成这套退场，关闭或收录返回场景时，所有控件先隐藏，再按进入空间时相同的顺序和节奏恢复，不以整页透明度代替。初次进入、空间退出和阅读页开关都复用相同函数；切页清理未完成的 UI 动画。阅读页返回时，场景相机以 0.65 秒恢复，0.7 秒后才启动同一套控件进场，完整播放后再释放导航锁定。

- 现场手记、记忆册、线索的开关沿用空间穿梭的径向光线和相同强度的动态颗粒；保留报纸折叠和线索上下推拉。退出、进入各自播放对应方向的粒子，长度跟随该阶段；纸面背景在折叠尾段一同淡出，结束后才更换路由。历史导航中断时清除粒子与临时状态。

- 线索位置直接跟随相机的实际 x/y，并在返回场景的第一帧同步；所有鼠标、拖动、回中与路由恢复使用同一偏移公式，避免线索先归零、鼠标移动后再跳向原偏移。关闭阅读页时也播放报纸音效，开启时的音效保留。

## 示意图

- 工具：锤头、锤柄和钢钎分层绘制，锤面 y=94 与钎帽 y=94 接触；围绕握柄处抡动，角度止于接触位置。落锤、石屑、回抡依次循环。两侧标注根据同一姿态坐标更新端点，文字保持水平。
- 协作：改为俯视人群示意。24 个圆点以实心 / 空心区分解放军、民工，从两侧错开进入，沿轨道两侧来到各自工位，短暂停留作业，再沿外侧离开。圆点在画外复位，轨道保持固定，不穿过钢轨；所有人群循环由同一个可暂停时间轴管理。
- 通车：编组统一为机车 → 两节客车 → 两节载矿石的敞车，取消紧挨机车的独立煤水车。客车有车窗、车门和连接器，矿车可见矿石堆与侧板。各轮组根据轮径和行程转动，连杆随动。通车页从 x=-124 行至 x=674；纪念碑页按 .55 比例从 x=-74 行至 x=536，车尾完全出画后才复位。
- 两幅列车图均在固定父层增加 0—360 用户坐标的 SVG 裁切区，确保车轮和车身不会显示在铁轨之外的视口留白中。
- 碑名取消远山、地面和石台装饰。左侧三条注解分别与路名、修路的人、纪念碑三个字组的中心对齐，不添加引线；注解高亮随字组的正向显字及反向回退同步。
- 碑名：字层按“成渝铁路 / 筑路民工 / 纪念碑”分组印出，高亮随阅读推进；完整停留 1.4 秒后按相反顺序逐字收回，括号、左侧高亮同步回退，空白处停留后开始下一轮。没有整层瞬间消失、移动纸张或虚影底字。
- 碑体：逐级描出四层碑体，再显示尺寸与日期；停留 1.4 秒后原时间轴反向播放，日期、尺寸、笔画和填色依次回退至底稿，再循环。列车独立保持前行循环，不随碑体倒车。
- 通车图补上远山轮廓、电线杆、成渝铁路标牌和小旗，固定沿线景物置于列车之后。

- 图下居中的独立短句统一去掉句号；正文段落保留正常标点。
- 示意仍遵循原文字资料，不作为实物测绘或历史照片。循环离开视野时暂停，切页时清理；减少动态效果时展示静态图。

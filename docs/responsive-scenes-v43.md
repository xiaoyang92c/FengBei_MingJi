# 桌面横图与线索位置 v43

本轮直接启用此前已经生成的三张横版原图，没有重新生成图片。电脑宽度至少 700px 且横向窗口时使用横图；手机和纵向窗口继续使用已认可的 v42 方形构图。记忆册、手记、资料照片保留上一轮的图片、轻降饱和度与裁切微调。

## 资源

- `public/assets/scenes/opening-wide-v43.webp`

三张横图均为原生 1672×941，以 quality 95 转码，原始 PNG 保存在 `output/imagegen/scenes-v43-desktop/`；原生成提示词仍见 `output/imagegen/scenes-v42/prompts.json` 的 `initialGeneration`。

## 取景

`src/scene-layout.ts` 统一选择图片并计算 cover 缩放、背景焦点与主体定位。桌面使用 108% 图像平面，手机使用 132% 图像平面。桌面碑图纵向焦点为 44%，通车图为 47%；焦点偏移限制在仍能覆盖整个视口且保留轻微视差余量的范围内，避免图片上沿露空。门框、穿梭与场景共用选中的图片和取景。窗口变化时立即更新背景和可见门洞；预加载缓存以图片路径区分手机与横版素材。

# 窗内外通行界面与穿梭 v23

2026-10-15。

## 通行票面

- 室内、窗外使用相同的 1.25 倍 UI 镜头层、底部锚点、票面样式。手机基础尺寸 184×46px，编号栏 42px；实际显示约 230×58px。桌面基础尺寸 214×56px，编号栏 48px，实际显示约 268×70px。窄于 350px 时票面宽度为 176px。
- 清除旧按钮的内边距和 gap 覆盖，编号、标签、箭头各在自己的网格区域居中。箭头改成几何居中的 SVG。
- 票面使用一条封闭 SVG 路径完成填色和描边，包含左侧凹口，不再用矩形 border 加 clip-path 切断描边。
- 标题与票面在横向切换 74% 时开始入场。移除逐字裁切和常态旋转，保留轻微纵向起伏，避免字形浮动时越过裁切区域。

## 穿梭

- 进入约 0.98 秒，power1.in，由慢推进入冲刺；退出约 1.02 秒，power2.out。
- 穿梭层只绘制一张场景图，视口自身无背景图。底层室内在交接前隐藏，避免两个不同缩放的画面同时出现。
- 窗框和裁切口共用同一缩放及中心坐标计算，场景从一半尺寸持续放大至全屏。按窗口和屏幕比例计算曲线，使裁切口首次占满屏幕时场景至少达到 94% 尺寸，并保留到结束的放大变化。
- 窗框按速度施加短暂模糊，场景本身不加速度模糊。横向切章使用 chapter-pull 曲线，墙面和门框一起施加横向速度模糊，停止后清除。
- 鼠标偏移在穿梭期间继续作用；共用光学镜头和颗粒，保持交接前后的画面一致。

## 环境动态

- 树影加强 X/Y 轴旋转、轻微错切及非等比形变，两层使用不同周期；保持第一章与第二章连续的投影位置。
- 常态镜头的低频与高频晃动振幅提高约 70%，同时扩大共享画幅余量，避免手机边缘露底。
- 减少动态效果时跳过穿梭、速度模糊、树影和镜头晃动。

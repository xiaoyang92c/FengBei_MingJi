# v5 透明入口与动态层

## 结构

选择空间的画面分四层：固定石墙位图、门内场景位图、带真实 alpha 开口的门框位图、动态树影位图。三扇门使用不同的展陈设计意象：纪念空间的素面木门、筑路工具展厅的粗木铁件门、档案展厅的木框磨砂玻璃门。它们不宣称是原建筑历史门扇。

门框是独立 RGBA 素材，中央开口与门外均为 alpha 0；房间画面放在开口后。石墙、树影不烘焙到门框或室内图中。标题上方留白，门框从视口约 28% 高度开始，移动端宽约 79vw。

## 动效

- 左右切换：上一幅完整墙面与门框以 `xPercent = -100` 移出，下一幅由 `xPercent = +100` 移入，约 1.15 秒，不做两幅叠化。
- 进入房间：门框和墙面整体向开口推进至约 3.9 倍，最后 18% 路程才让完整室内显现；室内画面同时由较近焦距退回正常镜头。返回反向移动。
- 石墙树影：透明 PNG 独立覆盖，约 11 秒小幅平移、旋转、改变浓淡。动态噪点由 112×112 的 canvas 每约 130 毫秒重绘，叠于场景与界面。
- 鼠标移动：墙面约 2.3° 水平与 1.5° 垂直倾斜，房间内约减半；移出页面回正。触控拖动仍用于场景观察。系统减少动态效果时关闭树影、颗粒和长转场。

## 生成素材与性质

内置 imagegen 生成：`portal-wall-v5.webp` 为无门、无树影的石墙；`portal-{monument,worksite,archive}-v5.webp` 为透明开口门框；`gallery-{monument,worksite,archive}-v5.webp` 为同一旧铁路纪念建筑展陈室内；`portal-view-monument-v5.webp` 是门洞中可见的无铭文小碑预览；`tree-shadow-v5.webp` 为透明树影。所有素材均属于**艺术表达**。正式史料与实地结构须另行核实授权。

生成提示词约束：建筑取 20 世纪中期朴素木材、石材与灰泥质感；门框中央和外侧必须透明；房间不含可读伪史料；纪念碑预览无文字；避免橙色光晕、镜面装饰与过度完美对称。门框外观只为叙事展陈，不作为原建筑形制证据。完整文件与核实状态见 `public/assets/asset-manifest.json`。

## 局限

室内视差来自分层位图和 Three.js 纪念碑，仍无法提供参考站原始摄影素材级别的连续摄影测量细节。穿门最后会以短暂显露连接门内预览和完整室内图；后续若能获得连续拍摄素材或完整空间模型，可以替换这一段画面，不影响线索、记忆册与来源交互。

# v7 一整条移动的石墙

## 结构

`#facade-track` 宽 `300vw`，承载一张 `portal-wall-long-v7.webp` 横向石墙位图与三扇固定在各自空间中心的透明门。切换空间时，GSAP 只移动这整个轨道 `0 → -100vw → -200vw`；墙、树影和门一起移动。UI 叠在视口上，不参与位移。墙面位图是一张文件，门与门之间没有两张墙图的接缝。

长墙通过 `python scripts/build_long_wall.py` 从现有 `portal-wall-v5.webp` 生成：三幅墙面素材重叠 230px 并羽化连接，输出 4556×941 WebP。它属于艺术化画面，不是建筑实景。原始石墙及长墙都记录在素材清单中。

## 进门与物件

门洞和下方按钮均可进入。门内与房间读取同一个 `Room.scene`；碑前为室外庭院，并在门内与房间叠加同一纪念碑静帧。房间内两条线索位于碑身与基座；筑路场景位于工具与轨排；档案场景位于文档柜。正式史料和精确碑体细节仍需核实。

进入时镜头使用先快后慢的推进，伴随短暂模糊、弱径向线条及用户开启声音后才播放的合成穿梭声。切换时整条墙轻微速度模糊。页面保留弱颗粒、树影和周边暗角；减少动态效果时关闭这些持续动效与长转场。鼠标移动引起选择墙面和房间轻微视角偏移。

## 局限

这是一张宽墙位图与分层门、场景图片构成的空间错觉，不是参考站的原始连续摄影或完整三维扫描。门内到房间使用同一图片和同一碑体静帧，但不同开口与全屏视口的裁切仍会改变可见范围。新室外素材生成请求触发了服务额度限制，本轮使用项目已有庭院画面。

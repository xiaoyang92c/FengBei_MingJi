# 移动端布局、音频与性能调整

## 加载数字

- 以桌面 Consolas 的 0–9 和 % 轮廓绘制 SVG，不依赖手机系统字体，不分发字体文件。
- 根据数字与百分号的可见轮廓总宽居中；0–99 与 100 使用同一计算方式。
- 移除原来的三字符最小宽度、右对齐、进度条横向偏移和数字抖动。
- `scripts/build_loading_digits.ps1` 负责重新生成矢量轮廓。

## 开关与布局

- 手机体感开关位于音乐开关左侧，复用胶囊纸纹、描边、字号与状态分隔线。
- 两个开关放入同一 `.scene-controls` 容器，与场景控件同时出入场；阅读时不会遗留独立的体感按钮。
- 手机标题定位在门框上方；门框与字号同时约束在可见视口高度内，适配较矮屏幕与浏览器工具栏。
- 删除随行提示及音频加载失败提示，不把正常缓冲显示成错误。

## 窗口选择性能

- 粗指针设备在选择页将预览图直接放在门洞的原生裁切容器中，切换仅移动合成图层。
- 进入、退出空间时仍复用同一张图，恢复完整门洞投影和连续推进；手机端的预览不再每帧测量多个 DOM 边角并生成全屏裁切路径。
- 手机关闭滑动中的超宽 SVG 动态模糊、全屏桶形位移及墙面卷积滤镜；树影使用轻微位移动画。
- 拖动复用 `gsap.quickTo`，不再为每个指针事件创建一个新 tween。
- 手机颗粒画布限制到 200×130、8 次/秒，电视和文档页暂停公共场景颗粒与镜头摆动。

## 手机音频

- 长背景音乐继续使用流式 HTML 音频播放，经过 `MediaElementAudioSourceNode → GainNode` 混音，避免 iPhone Safari 的媒体元素音量限制。
- 窗口增益为 0.36，场景与片尾为 0.075；使用音频时钟上的增益包络衔接。晚完成的 `play()` 不会覆盖当前场景的低音量。
- 首次触摸或键盘操作即解锁音频；电视菜单期间背景音乐以零增益准备，进入窗口后正常播放。
- 手机流式版本为 AAC 96 kb/s、44.1 kHz、faststart M4A，来源和内容与原 MP3 相同，体积约为原来的一半。
- 正常缓冲交给浏览器继续加载；实际网络失败才重载并退避重试。页面隐藏时暂停，返回和再次触摸时恢复；场景音效也会静默重试。
- 原始音频保留以记录素材来源。实际 Safari、微信内置浏览器、电话中断及后台恢复仍需真机确认。

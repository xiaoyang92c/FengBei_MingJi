# 电视开机序幕

开场直接进入 CRT，不再出现木门、开门按钮或门声音源。

## 开机顺序

1. 屏幕尺寸始终固定。黑场中电子束亮线先化为柔和磷光，黑场遮罩在约 1.3 秒内连续退去，背景与预加载数字接续亮起；不缩放玻璃或画布，不直接从亮线切到整幅背景。
2. 调谐数字与细进度条出现，数字持续微晃。进度的 74% 来自资源任务完成比例，26% 来自 3.2 秒的画面暖机；两部分都完成才显示 100%。减少动态效果时暖机缩至 0.25 秒，数字不晃动。
3. 预加载任务包含三张场景、三个窗框、墙面、树影、纸张与字体。复用现有场景缓存，失败任务按 settled 计数，异步完成不更新已经离开的页面。
4. 预加载标签逐字显现，数字、百分号和进度条分别渐入，状态文字切换也逐字显现。画面锁定后隐藏调谐数字，标题、声道菜单和台标按行逐字点亮，随后开放操作。

## 视觉与交互

- 丰碑与铭记五个字使用同一种字体、字号、字重与颜色。
- 两个入口采用屏显菜单，带三角光标、编号、声道开关标识和独立的浅金色磷光选框。加载完成时不显示框；首次点击选项后，完整外围线框先以 -2px、+2px 的水平错位闪两次，在 0.25 秒处归位并持续显示。框的尺寸始终完整，没有中央亮带、上下展开或穿过文字的图形。减少动态效果时直接显示完整选框。移动与停留始终使用同一 #d5cb91 色值，不附加点击变色或另一层浏览器焦点框。选框属于节目画面，继承同一轻微曲屏和扫描线，失焦或鼠标移出不会消失。
- 点击采用两次确认：默认高亮不算首次选择；第一次点击仅选定并显示“再次确认进入”，第二次点击同一项才开始离场。切换另一项时，选框用 0.38 秒纵向移动，重新开始两次确认。悬停时亮底跟随鼠标所指的按钮，移出后恢复到已选项，保留音效与文字反馈；悬停不移动选框或改变待确认的声道。Tab 和上下键可移动选择，Enter/空格首次确认选定、再次确认进入；按住按键不会连续触发两次，Escape 可取消待确认状态。移动端保留简短操作提示。
- 主内容上移 18–22px。文字、菜单、进度数字和扫描线通过一张静态桶形位移场轻微弯曲（强度为视口短边的 5.5%，上限 34px，约为初版三成），保留真实可交互的 DOM；颗粒与滚动带位于滤镜外，避免随噪点频繁重绘曲屏滤镜。开机与稳定阶段都使用 0.055 的颗粒透明度和 0.15 秒更新间隔。
- 只有电视内部出现柔绿余辉、扫描栅格、低幅静电颗粒、低幅亮度波动与偶尔串影。开场独立管理自己的 ticker、时间线、噪点和事件，切页全部清理。
- 原有场景风声、纸张声与铅笔悬停声继续遵循声音开关。电视开机使用用户提供的 tvon-off.mp3；画面稳定后，在首页循环播放 tv-low-buzzing.mp3，离开首页时淡出。首次访问会尝试自动播放，若浏览器拦截，则在首次点击或按键后恢复当前环境音，不迟播已经过去的开机声。

按用户要求不进行浏览器画面检查，由用户查看预览。

## 选择进入的交接

有声和静音入口共用同一时序：选中项短暂确认，所有可见文字按字错位、闪断并伴随横向切片残影消散，菜单高亮和图标随之消失；之后仅电视发光画面压成亮线，亮线收为光点熄灭，固定玻璃本身不缩放。约 1.66 秒后在暗场下切到第一章窗口，墙面、门框、窗景共同渐入，再出现标题、票面、左右箭头和声音开关。入场与离场挂在同一导航时间线上，浏览器返回可以取消并清掉遮罩及透明度。

## 电视音轨

- 保留 tvon-off.mp3 原始录音。开机使用其 0.42—1.98 秒片段（tv-power-on.wav，1.56 秒），关机使用 0.52—1.52 秒片段（tv-power-off.wav，1 秒）。裁掉前导弱声，两段各有 12ms 起音与 0.18/0.26 秒尾部淡出。音量 0.48，分别在开机 0.08 秒、关机 0.78 秒处触发，关机声的强音对齐画面开始收束；切换到窗口后仍播放完整尾音，不因路由替换而截断。
- 开机亮线和音效共同等待开机声音解码后开始；其他照片、字体等仍按原预加载流程载入。短音若受自动播放限制或加载延迟超过 120ms，不迟播到错误的画面上。
- 保留 tv-low-buzzing.mp3 原始录音。约 13.15 秒有突出尖峰，循环改用 0.35—12.10 秒的稳定部分，去除直流偏移，将首尾 1.2 秒做等功率交叉渐变，输出 10.55 秒的 tv-buzz-loop.wav。音量从 0.18 提到 0.45（约 +8dB）；开机 1.6 秒后开始，0.8 秒渐入，离开首页以 0.45 秒淡出。
- 三段派生音频使用 PCM，Web Audio 解码后由 AudioBufferSourceNode 在音频时钟上播放。环境音通过采样级循环衔接，不使用 HTMLAudio 的 MP3 循环或 JavaScript 定时拼接。复现脚本为 scripts/prepare_tv_audio.py，依赖 FFmpeg 和 NumPy，包含无削波、首尾幅度和尖峰检查。
- tv-button-hover.mp3 用于两个进入按钮的悬停与键盘聚焦，音量 0.38；按钮内部子元素之间移动不重播，初始自动聚焦不发声。移出、失焦和切页时以 45ms 淡出，静音和页面隐藏也以短渐变释放音轨，不直接暂停到零。
- 第一次选定和第二次确认也播放同一电视按键录音。点击声独立于悬停，鼠标移出不会将点击声截断；第二次确认后留出 0.26 秒让原长约 235ms 的录音播放完，再执行静音或电视离场。
- 首页不播放叙事 BGM。每次进入首页都默认开启声音，包括从静音故事返回首页；有声/静音入口控制后续故事的声音。浏览器若拦截首次自动播放，首次点击或按键会恢复当前电视环境音，已过去的开机声不补播。页面隐藏会停止电视声音。
- 页面关闭、热更新和浏览器返回会清理或重新对齐音轨状态，阻止延迟加载的旧开机声在其他页面突然播放。

## 与终章呼应

屏幕结构、静态曲屏、低分辨率噪点和显字工具已抽到 crt-display.ts，首页与电视片尾共用；首页的实际素材进度、两次确认、声道选项与进入第一章窗口的时序保留。终章同样使用电视开机、低鸣、按键与关机音轨，首页暂停叙事 BGM；终章保持故事 BGM（0.075）与电视低鸣叠加。

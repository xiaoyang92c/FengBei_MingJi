# v28 穿梭绘制与节奏

## 绘制

- 墙面、原始门框与投影共用外墙推进变换，不再交换临时门框。
- 穿梭时将原有场景图片移动到相机下独立绘制，以门洞四角的投影坐标裁切；过程不克隆照片。避免浏览器将门洞的小尺寸缓存放大，造成场景像素化。
- 窗内和室内使用同一高清素材、同一镜头处理与 16% 画幅余量。图片连续从半尺寸放大到全尺寸，支持过程中的鼠标位置和角度变化。
- 近距离失焦仅作用于门框和墙面；公共镜头不包含动态模糊。门框覆盖屏幕后才开始失焦。投影随接收墙面离开而淡出，返回时恢复。
- 完成和历史导航中断时归还原图片、移除裁切层、清零失焦和外墙缩放。

## 节奏

- 进入 1.65 秒，退出 1.45 秒。单条连续曲线从静止蓄力、加速到收稳，不串接中途暂停。
- 外墙使用指数尺度推进，避免线性尺度在开始瞬间就跨越大部分可见距离。
- 场景早段平滑补足竖向门洞的画幅，后段继续放大，避免提前锁死最终大小。

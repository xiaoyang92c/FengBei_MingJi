# v10 选空间交互与墙面

- 三扇门、整幅石墙、整幅树影共用一条横向轨道。桌面轨道间距为 `100vw`；窄屏为 `132vw`，避免相邻门过近。墙和树影用 `background-size: cover` 保持素材比例，同时填满最宽视口和首尾拖动的缓冲区。
- 标题和“进入空间”按钮各自位于对应门的文案面板。文案镜头与门镜头共享位移、透视旋转和鼠标偏移；拖动时旧文案随门移动并逐渐淡出，新门停稳后文案才淡入。松手后的滑动从当前轨道位置继续，边界拖动有橡皮筋阻尼。
- 石墙、树影和展陈门均为艺术表达。墙面使用完整长图，光影和色调在整幅长墙上统一叠加，不按章节分片；树影作为独立透明层以 11 秒周期缓慢移动。声音开启后，横向切换附带轻微滑动音效。
- 原有纸角折叠悬浮动画已移除。减少动态效果时，空间切换立即完成，文字也会正常显示。
- `scripts/build_long_wall.py` 可从现有长墙母版和透明树影重建当前三张 v10 素材。桌面和手机共用同一张墙面位图，只调整取景范围；此版本沿用已生成的石材纹理。新的主题墙面生图因图像生成额度限制尚未完成，后续可替换同尺寸素材而不修改交互。

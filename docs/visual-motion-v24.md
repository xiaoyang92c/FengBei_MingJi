# 流体投影与间歇光效 v24

2026-10-15。

- 树影移除整层旋转、缩放、错切和摆动。保留连续投影的位置，以静态低频噪声场驱动局部像素位移；只移动位移场并改变形变幅度。按追补反馈，位移幅度提高到 42–64，周期分别为 8.4、11、7 秒，使用连续样条过渡，局部扭曲更明显。
- 位移滤镜只作用于阴影图片本身的 3:1 区域，使用单层、单 octave 噪声，避免为整个墙面生成动态噪声；原有第二层重复投影隐藏。
- 编号分区再加宽 6px，并将编号的光学校正向右 2px。手机编号栏 48px，桌面 54px；票面总尺寸保持不变，虚线与编号一起向右调整。
- 整张票面与标题共用 21.6 秒循环和 1 秒起始偏移。顺序为故障一（约 3.2s）→ 白色扫光（约 8.6s）→ 故障二（约 14s）→ 白色扫光（约 19.4s），两次故障的中间只出现一次扫光。光带从编号、虚线、文字到箭头依次经过；亮白窄反光线配两侧宽柔光，screen 混合只提亮底色。箭头向左移动 3px，增加右侧留白。
- 标题主字形保持 opacity:1，移除变暗的 glyph-signal。glyph-echo 与 glyph-splice 两种明亮的切片错位每约 10.8 秒交替，按字错开；各自使用 21.6 秒循环，局部回声总时长约 0.2 秒。
- 减少动态效果时停用流体位移、文字故障与扫光。

验证：`npm run build`、`git diff --check`；浏览器读回树影的 animation 和 transform 均为 none，滤镜为 foliage-flow；手机网格为 48px / 96px / 40px。追补核对主字 opacity:1、仅有 glyph-breathe，双伪元素分别为 glyph-echo、glyph-splice，票面为 pass-sweep。布局截图见 `output/mobile-select-v24.jpg`。

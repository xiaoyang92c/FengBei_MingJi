# 体感与移动端转场兼容调整

本次针对手机实测反馈中的默认体感状态、穿梭卡顿、夸克窗口图片闪动，以及微信/夸克折页图层异常进行调整。在线入口为 <https://fengbeimingji.vercel.app/>。

## 体感

- 所有浏览器默认关闭，不在未点击时监听传感器。
- 可见状态只有“关 / 开”。请求或连接过程不显示为开启，收到有效事件才显示“开”。
- 相对姿态仍使用四元数；死区 0.35°、有效倾斜响应区间约 14°、偏移上限 ±0.6。相较 v46，小幅动作响应增强，上限提高 50%。
- 手机视差改为平移，场景偏移在素材覆盖区域内限幅；进入新场景后从当前握姿重新校准。

## 手机穿梭

旧实现会把图片在门洞与屏幕投影容器之间移动，逐帧测量多个 DOM 边角，再在动画末段重建场景界面。新的手机路径：

1. 门洞预览与穿梭照片各自常驻，不再移动同一个图像节点到新父容器。
2. 开始时只测量一次门洞；之后根据纯几何计算更新裁切容器和照片的合成变换。
3. 目标照片提前解码、准备，重叠两个绘制帧后才移交显示。
4. 手机界面在镜头结束后构建，目的画面先在照片下方绘制，再释放覆盖照片。
5. 视口尺寸变化延后到穿梭结束统一处理；浏览器历史返回会取消旧动画及清理图层。
6. 门框已经移出屏幕后停止绘制放大的墙面；暂停公共镜头摆动与颗粒，减少穿梭粒子数量和画布分辨率。

投影还根据源照片实际着色区域、取景裁切及当前视差计算最低缩放量，确保进退过程的每一帧都覆盖可见门洞，避免横屏或倾斜后出现短暂空白边。

桌面继续使用原有透视穿梭。

## 纸页

- 手机保留纸页折合动作，用两个独立的二维投影表面表示正反面；不再依赖嵌套 `preserve-3d` 与背面剔除。
- 两面在折线附近明确切换透明度，任何时刻不同时显示；透明度为零能完整隐藏包含 `visibility:visible` 子元素的纸面。
- 正文使用统一的折叠状态隐藏。快照保留阅读滚动位置、去除重复 ID，暂停动画与多余的合成层提示。
- 展开结束后正文先显示，保留两个绘制帧的快照覆盖后再移除；关闭时也先准备快照再隐藏正文。
- 记忆册和现场手记共用同一个折页控制器，路由中断、窗口尺寸变化和卸载会停止并清理旧动画。

## 验证与边界

执行 `npm run build`、`node scripts/check-device-tilt.mjs`、`node scripts/check-mobile-runtime.mjs`、`node scripts/check-transitions.mjs`。

传感器检查覆盖默认关闭、用户授权、超时、校准和清理；转场检查覆盖不同手机尺寸下的覆盖范围、投影对齐、图像终点、折页两面的互斥、滚动快照和延迟清理。

遵循此前不做浏览器视觉检查的要求，本次不声称已在真实微信、夸克或 iOS 设备上验证绘制结果；真机流畅度与合成器兼容性仍需复测。

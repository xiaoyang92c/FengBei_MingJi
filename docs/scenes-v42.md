# 三处写实场景 v42

后续桌面横版与线索定位调整见 `responsive-scenes-v43.md`；下文记录 v42 生成与最初的统一方图接入过程。

## 场景与线索、声音

| 空间 | 主体与线索 | 对应现有环境音 |
| --- | --- | --- |
| 开山筑路 | 居中直行双轨、砂岩路堑、钢钎与锤、背向劳动者；对应“钢钎与大锤”“一起修路” | 凿石施工声、人群声 |
| 铁路贯通 | 正面居中蒸汽机车、连续钢轨、年代相符的站台与背向人群；对应“全线通车” | 老火车、人群声 |
| 回到碑前 | 居中细长黄砂石碑、四级叠收碑座、树林与台阶；对应“碑上的字”“通车之后” | 清晨、森林自然声 |

工地与通车场景人物均以背向、俯身背向构图，避免正脸；碑前不安排人物。碑体参考 `output/reference/course-monument-photo.jpeg` 的轮廓、层级和材质。文字与形制依据仍为 [内江地方报道](https://site.scnj.tv/wap/showplay.php?id=1938901)。场景属于写实创作，不作为真实现场照片或测绘成果。

## 构图与接入

- 使用内置 `image_gen.imagegen` 生成三张初稿，再针对裁切重做三张正方形构图。最终原生尺寸均为 1254×1254；保留生成原图，不插值放大、不伪称 4K。
- 正方形母图为手机竖向裁切和桌面横向裁切保留主体。工地的轨道中线、机车正面中线、碑身与基座中线均以画面 50% 横坐标为中心。画面中央附近集中必要人物、工具与建筑，不继续使用偏斜轨道或一侧占重的机车构图。
- 门窗与室内沿用同一图片、132% 画幅和相同背景焦点。手机预览从 0.5 倍连续放大至完整场景，大屏预览按 `min(0.5, 820 / max(视口宽, 视口高))` 限制母图尺寸，避免固定高度的门框截掉碑顶；穿梭同样从此倍率连续放大，不更换另一幅门窗缩略图。
- 碑体完整轮廓的垂直中心约为源图 56.5%，在两个渲染入口共用同一个焦点偏移。正方形图片的 cover 边长为 `132vmax`，因此额外向上调整 `8.58vmax`，将碑的中心对准门洞与场景中心。
- 删除 `.scene-cube`、`sceneObject` 与相应移动端 CSS。清除线索正文、资源清单和当前说明中的方体占位描述。
- 三处记忆册、现场手记与线索资料照片通过 `room.scene` 自动使用新版资源。

## 纸面照片微调

沿用上述生成图片，仅以 CSS 将纸面照片饱和度由 0.7 轻降至 0.62。记忆册、手记和线索页共用按房间设置的裁切焦点：工地由 60% 改为 50%，让人物稍微下移；碑前由 60% 改为 68%，让碑稍微上移；通车保持 60%。删除线索页沿用旧版横图的独立裁切覆盖。此调整不修改原图片，也不改变场景和门窗的背景焦点。

## 检查

检查生成图片的中轴、人物朝向、完整主体和材质；按 CSS 几何计算手机、桌面及门洞的中央裁切，检查主体是否落入可见区；通过 TypeScript / Vite 构建并确认资源输出。按用户既有要求，不调用浏览器做视觉测试。

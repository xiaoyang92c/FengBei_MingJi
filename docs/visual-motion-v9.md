# v9 选空间墙面和镜头

- 使用 `scripts/build_long_wall.py` 从原石墙采样生成 `portal-wall-long-v9.webp`。砖块尺度约为旧版的 65%，亮度和暖色曝光提高；三扇门仍与整张横墙同轨移动。
- `tree-shadow-long-v9.webp` 为三处入口分别变换方向和强度的树影，边缘与相邻区域渐隐。每处入口另外有不同方向的柔和暖光，不在门图中烘焙影子。
- 选择页相机保留 1.25 倍画幅余量，鼠标带动墙面透视倾斜；固定镜头暗角覆盖选择页与空间内画面。左右箭头按画面中线垂直对齐，纸质按钮悬浮时显露折角和轻微三维翻折。
- 换章时路由立即更新并推动整条墙，资料预载与文字出现并行。移除整张 300vw 墙面的动态模糊滤镜。到第一处和最后一处时，反向拖动只有很小的回弹，并限制在镜头余量内。
- 手机端门宽设为 `58vw`，再受相机倍率影响；支持 390px 和 320px 视口。

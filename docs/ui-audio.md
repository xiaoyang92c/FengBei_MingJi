# 界面录音音效

三个用户音源原样复制到 public/assets/audio，不重编码。

| 交互 | 资源 | 原时长 | 播放增益 / 时长 |
| --- | --- | --- | --- |
| 进出场景 | ui-travel-wind.mp3 | 2.024490 秒 | 0.29 / 进入 1.65 秒，退出 1.45 秒 |
| 箭头、键盘切窗 | 同上 | 同上 | 0.29 / 随切窗时长，至少 0.6 秒 |
| 拖动窗口 | 同上 | 同上 | 松手确认切到相邻窗口后播放；不足阈值、越界、取消或回弹均不播放 |
| 记忆册、手记、线索打开 | ui-paper-open.mp3 | 1.838299 秒 | 0.48 / 完整播放 |
| 铅笔涂鸦悬停、键盘聚焦、触控 | ui-pencil-hover.mp3 | 0.729070 秒 | 0.30 / 0.72 秒 |

通过同一个 AudioContext 解码缓存，三路单次音效互相独立。同类音效重复触发会以短淡出结束上一段，避免快速悬停叠加。铅笔控件子元素之间移动不重新播放；移出、失焦、切页会取消未完成的悬停请求。风声裁切处保留 0.2 秒淡出。

声音开关同时控制背景音乐、场景环境音和界面音效；静音与页面隐藏会取消待加载的播放，并淡出当前音效。开场已改为自动电视暖机，木门动画与木门录音均移除，暖机改用用户提供的 tvon-off.mp3，稳定后在首页循环播放 tv-low-buzzing.mp3，细节见 tv-cover.md。减少动态效果不关闭音效。

替换了此前合成的纸张噪声。未自动打开浏览器或进行试听；最终混音可由用户在预览中调整。

## 阅读页关闭

- 现场手记、记忆册和线索开始关闭时播放 paper 音效，音量 .48，与打开一致；沿用音频管理器的淡出规则。声音关闭时仍保持静音。
